# March 2026 History

This archive keeps March 2026 implementation history. Entries are ordered from
oldest to latest.

## v1.5.1 Original Version

`v1.5.1` is the earliest recorded version in the previous README history.

## v2.0.0 Custom Save Path

`v2.0.0` introduced the native messaging host, background service worker,
configurable popup, date-prefixed filenames, and improved article detection.

## v2.1.0 Responsive Page Cleanup

`v2.1.0` fixed content duplication on responsive pages, improved sidebar
exclusion through drill-down, and expanded author extraction through JSON-LD
`organizer` and `publisher` fields.

## v2.2.0 Image Support

`v2.2.0` preserved `<img>` elements as Markdown image links.

## v2.2.1 Unicode Filename Slugs

`v2.2.1` fixed filename slugs for non-Latin titles, including Cyrillic and CJK
text, by using Unicode-aware matching.

## v2.3.0 Reddit Post Body Fix

`v2.3.0` fixed Reddit post-body extraction through shadow DOM traversal and
smarter drill-down. It also filtered AutoModerator-style bot replies.

## v2.4.0 Reddit Extraction Improvements

`v2.4.0` improved Reddit extraction for self-posts and comments across shadow DOM,
removed Reddit UI noise, and exported comment threads as clean Markdown.

## v2.5.0 LinkedIn Job Extraction

`v2.5.0` added LinkedIn job-page extraction that targets the job description and
strips Premium prompts, similar jobs, and other LinkedIn chrome.
