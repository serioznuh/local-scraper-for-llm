# May 2026 History

This archive keeps May 2026 implementation history. Entries are ordered from
oldest to latest.

## v2.6.0 Reddit Thread Metadata

`v2.6.0` added Reddit post/comment timestamps, nested reply-thread Markdown,
deleted-author comment preservation, avatar filtering, and Codex project
guidance.

## v2.6.1 Reddit Comment Hydration

`v2.6.1` waited for lazy-loaded Reddit comments before scraping so hydrated
threads would not export as post-only Markdown.

## v2.6.2 Reddit Virtualized Comments

`v2.6.2` kept Reddit comments mounted during extraction after forced
comment-section scrolling, fixing virtualized threads that exported as post-only
Markdown.

## v2.6.3 Reddit Date Formatting

`v2.6.3` formats Reddit post and comment timestamps as date-only values and reads
post dates from Reddit post-level attributes.

## Documentation Quality Gates

The project added explicit agent guidance for quality gates, verification,
privacy/security constraints, and release checklist expectations.

## v2.7.0 Settings And Output Actions

`v2.7.0` adds a dedicated options page, versioned local settings, optional
Markdown text clipboard copying, optional macOS saved-file clipboard copying,
macOS folder picking, and macOS-only open-after-save support through the native
host. The toolbar icon is now the scrape trigger; Settings owns configuration
and latest status.

## v2.7.1 Reddit Comments Section Fallback

`v2.7.1` recognizes Reddit's current comment markers and adds a visible-text
fallback when structured comment containers are not usable, so exports include
loaded comments instead of saving post-only output while avoiding sidebar chrome.
